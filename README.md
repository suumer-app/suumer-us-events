# Suumer US Local Events: weekly snapshot

Every upcoming public event listed on [Suumer](https://suumer.com), the free guide to what's on near you in the United States: title, kind, date and time, venue, town, state, and a link to the event's page on suumer.com. CSV and JSON, refreshed every week.

The first files are on their way; they appear under [Releases](https://github.com/suumer-app/suumer-us-events/releases).
